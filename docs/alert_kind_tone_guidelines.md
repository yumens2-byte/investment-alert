# Alert 친근 톤 가이드라인 (F감성 일상대화체)

> **목적**: investment-alert의 X/Telegram 출력 포맷을 기계적 톤 →
> 30대 직장인 여성을 포함한 다양한 독자에게 다정한 톤으로 전환.
>
> **버전**: alert_formatter_kind.py v1.0.0
> **연관 문서**:
> - `publishers/prompts/alert_kind_l1_claude.md` (L1 프롬프트)
> - `publishers/prompts/alert_kind_l2_l3_gemini.md` (L2/L3 프롬프트)
>
> **타겟 효과**: 본 알림 정합성 유지 + 친근감·신뢰감 강화

---

## 1. 핵심 원칙 4가지

### 원칙 1 — 사용자에게 말 거는 톤 (You-centric)
"Score 8.2 | 판정근거..." → "오늘 시장이 많이 흔들렸어요. 잠깐 같이 살펴볼게요."

### 원칙 2 — 친절한 해석 (What-it-means)
숫자만 던지지 않고, **일상에서의 의미**를 1줄.
"VIX 32" → "공포지수가 평소의 2배 수준이에요."

### 원칙 3 — 다정한 균형감 (Calm but caring)
긴급도는 유지하되 위협적이지 않게. 토스/카뱅 톤.

### 원칙 4 — 등급별 톤 차등 (Level-aware)
L1 차분·분명 / L2 다정·관찰 / L3 부드러움·여유

---

## 2. 등급별 톤 매트릭스 (확정)

| 등급 | 헤더 | 톤 | 마무리 문구 후보 |
|------|------|-----|--------|
| **L1** | `🔔 잠깐 살펴봐요` | 차분·분명, 절제된 긴장감 | "마음 단단히, 차근차근 봐요" / "한 번 같이 정리해 봐요" |
| **L2** | `📬 오늘 시장 메모` | 다정·관찰, 카페 대화 | "잠깐 챙겨봐요" / "한번 같이 봐 둘게요" |
| **L3** | `🌿 가볍게 한 번` | 부드러움·여유, 일상 | "참고만 해주세요" / "오늘은 이 정도면 충분해요" |

**유지 항목** (절대 변경 금지):
- 위협 어휘 회피
- 등급(L1/L2/L3) 자체는 백엔드 그대로
- "투자 권유 아님" 면책 (표현은 친근하게)
- 25 안티봇 변동 (시간문구·해시태그·온도)
- 비한국어 가드

---

## 3. 말투 규칙

| 차원 | 설정 |
|------|------|
| 인칭 | "저" / "우리" (가까운 톤) |
| 종결 | "~네요/~어요/~거든요/~더라고요/~같아요" 위주 |
| 평어 비중 | "~다/~았다"는 강조용 가끔만 (20% 이하) |
| 호흡 | 한 문장 평균 17~22자 |
| 이모지 | 헤더 1개 + 본문 0~1개 (절제) |
| 해시태그 | 기존 `_X_HASHTAG_POOL` 그대로 사용 |
| 거리감 | 적당히 친근, 과친절 금지 |

---

## 4. 절대 금기 (LLM 프롬프트에 강제)

| 카테고리 | 금기 |
|---------|------|
| 정치 | 대통령, 정당, 국회, 여당, 야당, 의원, 선거, 정치 |
| 젠더 | 페미, 젠더, 여성·남성 일반화 |
| 종교 | 신, 예배, 교회, 기도, 종교 |
| 사적 | 결혼, 출산, 미혼, 외모 |
| 권유 | "사세요", "매수하세요", "추천", "꼭", "반드시" |
| 단정 | "확실히 폭락", "반드시 오른다", "100%" 류 |
| **위협** (신규) | "위기", "폭락", "공포", "긴급", "심각", "위험", "충격" |

L1조차 "위기/폭락" 같은 위협 어휘 사용 금지. **위협 회피와 긴급도 전달 분리**가 핵심.

---

## 5. 콘텐츠 결합 패턴 3요소

1. **헤더 + 한 줄 핵심 요약** (사용자에게 말 걸기)
2. **데이터 + 친절한 해석** (숫자가 의미하는 것)
3. **면책 문구 + 마무리** (참고만 / 차근차근)

가끔 4번째 요소 추가:
4. **공감·전환 한 줄** (확률 20~30%) — "그래도 너무 무서워하지 말아요" 류

---

## 6. 검증 (시스템이 후처리로 강제)

LLM이 가이드라인을 어겨도 시스템이 잡아낸다.

| 검증 | 기준 |
|------|------|
| 길이 | X: 80~270자 / TG: 200~1500자 |
| 위협 어휘 | `위기`, `폭락`, `공포`, `긴급`, `심각`, `위험`, `충격` 차단 |
| 권유 어휘 | `사세요`, `매수하세요`, `추천` 차단 |
| 정치·젠더·종교 | 차단 (기존 도윤 페르소나와 동일) |
| 면책 문구 | "참고", "권유는 아니에요", "참고만" 중 하나 포함 필수 |
| 비한국어 | 기존 `_NON_KR_PATTERN` 재사용 |

검증 실패 시: `None` 반환 → 호출자(`alert_formatter.py`)가 기존 AI 트윗 또는 템플릿 fallback.

## 7. 모델 분담 (Claude + Gemini 듀얼)

| 등급 | 모델 | 근거 |
|------|------|------|
| L1 | **Claude Sonnet 4.5** (`claude-sonnet-4-5`) | 톤 정확도·금기 어휘 회피 안정성 |
| L2 | **Gemini 2.5 Flash-Lite** (`gemini-2.5-flash-lite`) | 빠름, 토큰 효율 |
| L3 | **Gemini 2.5 Flash-Lite** | 동일 |
| 영문 뉴스 한국어화 | **Gemini 2.5 Flash-Lite** + 1주 캐시 | 비용 효율 |
| Fallback | 기존 `_generate_ai_tweet` (Gemini) → `_format_x_template` | 안전망 |

환경변수 토글:
- `KIND_TONE_ENABLED=true` 시 신규 톤 활성
- `KIND_TONE_L1_MODEL` (선택) — L1 모델 토글
- `KIND_TONE_L2_MODEL` (선택) — L2/L3 모델 토글

## 8. Before / After 시뮬레이션

### Before (현재 L1 X 트윗)
```
🚨 [긴급 Alert]
Score 8.2 | VIX 32.5 급등(+45%), 미국 채권 10년물 4.85% 돌파, S&P 500 -3.2% 마감.
📰 Treasury Yields Surge Past 4.8% on Inflation Fears...
#InvestmentOS #미국증시
```

### After (예상, L1 — Claude 생성)
```
🔔 잠깐 살펴봐요

오늘 미국 시장이 평소보다 많이 흔들렸어요.
공포지수가 평소의 2배 정도로 올랐고, S&P 500은 -3.2%로 마감했네요.
연준이 금리 정책에 좀 더 단호한 분위기인 것 같아요.

투자 권유는 아니에요. 마음 단단히, 차근차근 봐요.

#미국증시 #시장경보
```

(위 예시도 "공포"라는 표현은 "변동성"이나 "긴장감"으로 LLM이 자동 교정할 수 있음. 시스템 검증 통과를 위해.)

## 9. 점진 활성화 (마스터 명령 패턴 준수)

| 단계 | 활성 채널 | 검증 기간 |
|------|---------|----------|
| Beta-1 | TG Internal만 (마스터 본인 채널) | 3~5일 |
