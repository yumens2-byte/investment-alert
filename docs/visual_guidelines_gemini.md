# Gemini 이미지 생성 비주얼 가이드라인

> **목적**: `image_gen_gemini.py` 모듈이 일관된 에디토리얼 미니멀리즘 비주얼로
> 헤더 이미지를 생성하기 위한 작가용(내부용) 가이드라인.
>
> **타겟 효과**: 30대 직장인 + 여성 유입을 확대하면서도, 기존 50대 남성 팔로워의
> 거부감을 발생시키지 않는 **중립적 에디토리얼 톤** 유지.

---

## 1. 핵심 디자인 철학

| 차원 | 방향 |
|------|------|
| 스타일 | The Economist 류 + 한국 라이프스타일 매거진 융합 |
| 톤 | 차분, 절제, 우아 (시끄럽거나 공격적 X) |
| 컬러 | 부드러운 뉴트럴 + 라일락 액센트 1점 |
| 컴포지션 | 70% 여백, 중앙 정렬, 단일 포커스 |
| 정체성 | 성별 중성, 연령 중성 (20~50대 모두 거부감 0) |

---

## 2. 컬러 팔레트 (확정)

### Primary
- **Off-white Beige** (`#F5F1EA` 류) — 배경 메인
- **Pale Blue Tint** (`#E5EBF2` 류) — 보조 영역

### Accent (1점 액센트만)
- **Muted Lilac** (`#C9B8D9` 류) — 핵심 포커스
- **Soft Sage Green** (`#B8CFC4` 류) — 대안 액센트

### 금기 컬러
- ❌ 강한 빨강 (`#FF0000` 류) — 공격적 인상
- ❌ 검정 단색 배경 — 위협적
- ❌ 형광색 — 저속 인상
- ❌ 미국 국기 컬러 조합 (적·청·백)

---

## 3. 컴포지션 규칙

### 레이아웃
- 16:9 비율 (X 헤더 + 일반 게시물 호환)
- 70% 여백 확보 (negative space 활용)
- 단일 포커스 (시각적 혼란 방지)
- 중앙 또는 좌측 1/3 정렬 (rule of thirds)

### 그래픽 요소
- 곡선 우선 (둥근 모서리, flowing line)
- 평면 일러스트 (그림자 거의 없음)
- 얇은 라인 차트 (1~2px, 부드러운 곡선)
- 점·동그라미 사용 (각진 사각형보다 우선)

### 텍스트
- 영문 짧은 헤드라인 1줄 (Nano Banana 2 텍스트 렌더링 90% 활용)
- 산세리프, 깨끗한 폰트
- 한국어 텍스트는 X 게시물 본문으로 보강 (이미지 내 X)

## 5. 시장 상황별 시각 코드

| 시장 상황 | 시각 코드 | 컬러 강조 |
|----------|----------|----------|
| 상승장 | 부드러운 상승 곡선, 라일락 액센트 | 라일락 |
| 하락장 | 차분한 하강 곡선, 채도 낮춤 (검정 X) | 페일 블루 |
| 박스권 | 수평 흐름, 둥근 점 분포 | 세이지 그린 |
| 변동성 | 부드러운 파동, 곡선 강조 | 라일락 |
| 매크로 (금리/환율) | 추상 기하 (원·선) | 페일 블루 |
| 빅테크 실적 | 기하 패턴 + 라일락 점 | 라일락 |

**핵심 원칙**: 하락장이라도 **위협적 비주얼 금지**. 차분함 유지.

## 8. 측정 기준 (사후 평가)

생성된 이미지를 다음 5개 차원으로 사후 검토 가능:

1. **여백률**: 70% 이상인가
2. **단일 포커스**: 시각적 혼란 없는가
3. **컬러 부드러움**: 강한 채도/검정 배경 없는가
4. **인물 중립성**: 성별·연령 식별 어려운가
5. **금기 요소 부재**: 마스코트·국기·정치 상징 없는가

5개 모두 충족 = PASS / 1개 이상 미충족 = 재생성
